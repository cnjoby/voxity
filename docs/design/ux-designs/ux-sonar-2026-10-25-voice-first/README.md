声呐只有一个常用入口：**开始**。你说想知道什么、想告诉谁，Agent 选择怎样完成。开始后可以熄屏，不需要选模式、管理任务或点消息。首次权限、设备绑定与故障准备在会话开始前完成。

## 用户会经历什么

| 原来需要操作 | 新的体验 |
| --- | --- |
| 先选私人查询、问问现场、现场互助、聊天、只收听 | 直接说“模力社区还能停车吗”“帮我问问现场的人”“找个人聊聊” |
| 我的任务：刷新、等待、继续、解决、结束 | “刚才问的有回应吗”“再放一遍”“继续问他”“不用等了” |
| 我的：开关现场互助、编辑关注 | “有相关问题可以问我”“今天别问我”“最近只关心停车” |
| 选择目标、消息类型、回复关系和来源 | Agent 结合当前地点、已播出的对话和意图处理；关键歧义只问一句 |
| 到列表里找声音并点击播放 | 有关本次需要的原声在合适空隙接续；“刚才那条再放一次”可重听 |

底层仍保存请求与回应，屏幕只镜像真实状态。取消“我的任务”页面不会丢失历史、追问关系或发送结果。

## 一段完整交流

1. 你点“开始”，说：“帮我问问模力社区，现在还能停车吗？”
2. 声呐理解这是向现场问人，检索已有合法信息并联系合适的人，不再让你选五个模式，也不再次确认同一意图。
3. 等待时你可以问天气、聊别的；系统不反复催促。
4. 车友有新回答，空隙中播放本人原声：“东门还有，刚才进去了一辆。”
5. 你说：“问他东门从哪条路进。”声呐接着同一段交流处理。
6. 你说：“知道了，不用等了。”结束这次追问；个人助手会话继续。说“结束”才关闭整个会话和麦克风。

没有现场回应，就如实说没有；不会拿合成样例补成现场答案。普通“现在还有车位吗”先私人查已有信息，查不到且需要公开问人时只问一句“要我问问在场的人吗？”

## 互助不再是开关

常用启动说明中明示“相关原声自动播；有相关提问时，愿意再答”。已有“只私人用”“不邀请我”“安静”等选择继续保留。没有先验拒绝的用户，点击开始仅为本次会话开放少量相关邀请；邀请由 Agent 筛选，人可以回答、拒绝或不理会。

唯一有效邀请刚播出，你直接说“东门还有三个位置”就能回应，不要求每次加“帮我回复”。接话对象和声源不清时不公开，必要时只澄清一句。

“先别问我”只影响本次会话；“今天别问我”保持到用户当地今天结束；“以后都别邀请我”存为长期偏好。自己的问题收到回答仍可播放，停止陌生邀请不等于取消自己的请求。系统不会替本人编造回答。

## 模型负责哪些选择

LLM 理解意图与上下文，决定查工具、找已有信息或建议问人；决策模型筛选值得打扰本人的邀请与播放候选。真实身份、授权、时效和音频抢占由规则执行。模型没有新的用户授权，不能扩大公开范围。

“帮我转告后面的车友”“回复他”直接执行明确动作；普通车内谈话保持私有。希望连续分享时说一次“这一路现场观察都帮我分享”，建立有边界的本次授权，之后正常分享不逐条确认。

## 落地顺序与验收

| 阶段 | 增量改变 | 可核对结果 |
| --- | --- | --- |
| 1. 统一入口 | 以“开始”替换 ExchangeSetup 五模式；首页只留准备与状态镜像；我的任务移出普通主流程 | 常用启动一次点击；已明确私人偏好保留；未就绪不伪装启动 |
| 2. 语音操作闭环 | 扩充现有 Agent 命令、会话内授权和任务读写；不把隐去的按钮仅改成关键词匹配 | 只靠语音可查、问人、听、回复、追问、重听、取消、改变参与意愿；无需任务 ID |
| 3. 不中断的体验 | 本地停声/结束、熄屏、播放插话、电话/断网恢复、长句分段 | 断网时可停；长句不截半公开；不会重发、串线程、把广播当本人分享 |
| 4. 联调与发布 | 模拟模式增加明确的全语音联调能力；保留三点切换、Bob 模力配置、来源标记；兼容旧固件/旧设置 | 手机换点只改本人；合成素材不冒充事实；Token、灵矽、音频、历史不重置 |

当前 `ExchangeService` 拒绝模拟点位自动会话，本轮只定义增量目标，不能靠删检查宣称全语音联调完成。先保留现行一条活跃现场问题上限，换新问题用一句自然澄清处理，不让用户管理并发任务。

设计检查、软件测试、生产发布、Android/ESP32 实机和真人体验分别记录。新方案验收核心是：**开始后遮住屏幕，一个人仍能走完提问—等待—听回应—追问—结束；并能在断网和播放时直接叫停。** 当前没有这轮实机通过证据。
