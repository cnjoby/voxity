# 真实坐标模拟联调与共享音频

2026-10-25。用户明确要求：手机可以在三个点位间切换并手动参与双向问答，ESP32 留在模力社区；全部模拟素材作为服务器数据供其他用户收听。

## 当前使用方式

覆盖安装 Android `0.1.4` / versionCode `5`，原设备 Token、灵矽绑定和私人配置保留。
首页选择“模拟位置”，点哪个地点，就同步哪个地点的真实 GCJ-02 锚点，按该坐标收听服务器声音和接收有效问答邀请。
不再从 APK 的 12 条本地素材填充当前列表。需要网络和原设备凭证；离线或未配置时显示连接状态，不用内置音频冒充服务器结果。

| 点位 ID | 地点 | 纬度、经度 |
| --- | --- | --- |
| `demo:modaily` | 模力社区附近 | 31.184698, 121.617324 |
| `demo:ai-island-19` | 人工智能岛19号楼附近 | 31.184820, 121.609497 |
| `demo:zhangjiang-jinke` | 中环路金科路口 | 31.173564, 121.602421 |

这些是公共地理锚点，不是手机 GPS，也不证明具体入口、楼层或人在现场。UI 与服务端 presence 标记 `simulated_place`，发布的原声作者标注“模拟位置”。
选择只改变本人位置，不改变其他用户；仍遵守静音、互助意愿、个人关注、问题/邀请期限及原声发布确认。
可以手动回答，未开放用模拟点位自动开启自然交流麦克风。普通 `android_mock` 仍受原规则限制，全局 `SONAR_ALLOW_MOCK_LOCATION=false` 保留。

用户已确认的临时 ESP32 固定配置为服务器私有环境中的 `SONAR_SIMULATED_PLACE_USERS={"bob":"demo:modaily"}`。
alice 没有固定点位，手机选择完全由 App 请求决定。早期为接通旧 APK 临时固定过 alice，此设置已撤销。
ESP32 正常轮询本人配置/位置时保持模拟点位；不伪造断网设备在线。
双方原有默认“愿意回答附近路口的拥堵问题”已调整为模力社区停车、路况与现场交流联调关注；静音、互助、凭证与平台绑定保留。

## 协议与退出

设备鉴权后调用：

```http
PUT /v1/me/simulated-place
Content-Type: application/json
Authorization: Bearer <自己的设备凭证>

{"expected_revision": 1, "place_id": "demo:modaily"}
```

坐标由服务器按注册点位选取，客户端不提交任意“真实 GPS”。未知点位 422、版本冲突 409；返回最新 profile 和 places。
该接口只变更本人位置，记录于新增 `simulation_choices` 表；不更改本人 Token、灵矽映射、关注、静音或互助开关。
前台约每 15 秒更新；保持原 60 秒位置时效。真实高德“模力社区”POI 和模拟锚点的坐标可匹配问答，不要求双方使用相同字符串 ID。

App 点击“手机真实位置”先撤销模拟点位，再走原生定位。显式客户端选择/退出优先于旧客户端的临时服务器固定配置，重启后也不会强行拉回旧点位。
服务端在发布时冻结模拟来源，旧客户端即使附带另一份录音位置，也不能隐藏当前模拟点位来源。

## 服务器上的全部 36 条素材

当前版本清单和 WAV 位于服务器 release 的 `demo-assets/`，不是依赖某台手机在线。
每处 12 条，公告、路况、闲聊三类各 4 条，全部保留原始 WAV 字节及 SHA256。

```sh
# 在部署 release 内，使用服务器私有环境与数据路径运行
python -m app.demo_audio --assets ./demo-assets --shared
```

共享模式发布为长期可主动浏览的 scene 示例，分类保存在 topics，原文字和声音不变。
“公告”类别也明确是测试样例，不伪造运营公告的有效时间；不作为实时路况/停车证据，不自动推荐出声。
返回 `synthetic=true`、`content_origin=agent_synthesized`、作者“合成测试音频”和来源说明；规范消息 body 也不标成真人原声。

旧素材记录和 WAV 历史保留，仅撤回本生成器的旧版本活跃样例；重复导入不增加重复记录。
共享样例没有每天过期的运营公告期限，直到明确撤回前都能主动浏览。访问仍需自己的设备凭证，不绕过用户隔离。

`GET /v1/voices?place_id=demo:modaily` 及对应真实高德 POI 都能返回该地 12 条样例。
其他用户的真实当前位置或手选 POI 在对应地理锚点附近时，也可以通过地点浏览访问这些共享样例。
