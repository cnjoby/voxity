# 张江测试音频与位置切换

日期：2026-10-24。范围：Voxity 仓库的 Sonar Android 与现有单机服务。

## 使用

首页点「模拟位置」，选择中环路金科路口、人工智能岛 19 号楼附近或模力社区附近。每处有 12 条中文音频：公告、路况、闲聊各 4 条，共 36 条、4 种合成音色。默认各展示一条，支持分类、展开、逐条试听和停止。音频随 APK 打包，无需网络、账号、定位权限或灵矽即可试听；仅主动点击播放，不自动连播、不公开、不产生交付回执。

首页点「手机真实位置」可退出测试模式，申请前台定位权限，使用 Android 原生 GPS / 网络定位。连接 Sonar 服务后由高德解析附近地点；离线且没有设备凭证时仍能尝试取得手机定位，但不能解析目标地点。拒绝权限、定位关闭或超时仍能回到模拟体验或手选询问目标。系统模拟定位持续标明测试来源，不能作为真实 GPS 验收。

模拟位置持久保存，重启后保留；切换时停止试听、取消旧定位与轮询，清除当前录制位置快照。在线服务先撤销真实在场资格，再处理附近邀请；离线时停止客户端刷新，已有服务器位置按原 TTL 失效。模拟模式用于主动浏览，不凭此获得真实在场资格。返回手机模式后重新取位置。已有草稿或录音未结束时不能切换，既有公开问题的目标保持不变；灵矽绑定和账号不变。

## 素材与重建

素材目录：`android/app/src/main/assets/demo/`。`manifest.json` 包含逐条文字、类别、音色、地点、秒数、SHA-256。音频是完整 16 kHz / 单声道 / 16-bit PCM WAV，每条约 4–5 秒，最长不超过服务契约的 8 秒；不是静音文件。

每条音频开头均说「模拟公告」「模拟路况」或「测试闲聊」，文字和页面也持续显示测试标识。公告、活动、停车及路况均为虚构测试情境，不能据此出行或判断现场。地点锚点为高德在 2026-10-24 返回的 GCJ-02 数据：

| 人工智能岛 19 号楼附近 | 121.609497, 31.184820 | 地理编码：川和路 55 弄 19 号，门牌号；仅作楼外附近锚点 |

macOS 已安装相应中文系统音色、ffmpeg / ffprobe 时，从仓库根目录重建：

```sh
python3 scripts/generate_demo_audio.py
```

使用本机系统语音合成，没有调用付费云服务；重建不裁切语音，超长时调整速度并检查完整 WAV。重建后重新构建 APK。

## 服务端联调素材

离线试听不依赖导入。需要用同一批声音检查真实服务端地点浏览、手动队列和提问时，在专用本机测试库执行：

```sh
cd server
uv run python -m app.demo_audio
```

先校验全部文件，再以独立测试作者和明确标记的测试公告频道导入 36 条，注册三个 `demo:` 地点。不会更换 alice/bob 凭证、用户配置或旧任务；重复执行不重复发布、不续期、不复活撤回内容。公告最长 24 小时（尊重服务器更短的上限），过期后不再出现在服务端有效公告中；离线测试素材仍可试听。所有导入素材为「适用条件未知」，只供主动查询，不自动推荐或播报。没有提供真实运营权限，也没有启用 `SONAR_ALLOW_MOCK_LOCATION`。

## 真机补充验收（2026-10-24 22:24，Asia/Shanghai）

设备为 vivo V2405A / Android 16。使用 Android SDK 自带 ADB 36.0.2 恢复无线发现，覆盖安装后比对设备 APK 与本机交付包 SHA-256 一致。安装前后连接、灵矽身份及任务偏好文件的摘要一致；完成系统安装验证后才继续测试。

首轮真机检查失败：系统返回 `source=android`、精度约 30 米，但采样时间已旧 254 秒。设备供应商对缓存位置的单调时间与采样时间存在不一致；客户端此前只校验单调时间，因此可能提前采用旧缓存、随后被服务器拒绝。现增加两种时间同时校验：采样年龄不超过 55 秒、未来不超过 10 秒，且单调年龄在 0–55 秒；旧缓存仅在既有 20 秒期限内继续等待，不以当前时间重写位置。增加回归检查，Android 单元测试现为 22 项；构建、Lint 与模拟器既有体验流程通过。

最终真机 `PhoneAcceptanceTest` 实际执行一项并通过：

- 原生定位 `source=android`、WGS84、精度 30 米，采样在检查时约 4 秒前；非注入坐标。服务端位置来源为 `android`，高德返回 6 个附近地点，页面显示定位已更新。
- 公告、路况、闲聊三条完整 WAV 通过应用现有 AudioCoordinator / MediaPlayer 播放，每条约 4.8–5.0 秒。三次均观测到正在播放、内置扬声器设备类型 2，以及自然播放完成；媒体音量为 40/150。
- 账号 Token、灵矽 Token 和设备身份比对保持一致。真实模式与旧模拟模式的任务存储独立；旧模拟草稿所在偏好文件与安装前摘要完全一致，原录音文件存在。早先将两个模式的页面草稿直接比较造成的测试失败已保留，最终改为在原存储范围核对持久化数据。
- 未录音、未发布、未丢弃用户草稿；应用留在真实定位模式。上面是程序与音频路由检查，实际听感仍等待用户确认。
