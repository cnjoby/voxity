## 2. 最终检查清单

| ID | 操作 | 预期结果 | 证据类型 |
| --- | --- | --- | --- |
| V1 | A 问路口→B 提示→B 自愿确认回答→A 播放，连续三轮 | 每轮ID独立，原声属于对应问题，提示只一次；来源与时间可查 | 双端实际操作及服务端任务记录 |
| V2 | 同地点，B 静音/关闭互助，A 发新问题；恢复后另发新问题 | 前者不打扰，后者提示；不重播旧邀请 | 双端设备；反例与正例均记录 |
| V3 | B 已提示后拒绝，或 A 取消，或等待邀请/问题超时 | 拒绝/取消后不再提示；邀请超时拒绝迟到回复；问题到期显示无人回应 | API 自动测试+设备 |
| V4 | 使 B 位置过期，A 位置不在提问目标处 | B 不收到邀请；不因问题提到路口就更新任一人的当前位置 | 可控时钟测试；无需真等十分钟 |
| V5 | A 等待时静音，B 回答，再恢复 A 收听 | A 看到已回答但未播放，原声保留；恢复后可播放 | 手机实际操作 |
| V6 | B 录音/TTS 时新邀请到达；播放途中静音/停止 | 不重叠；邀请播放前复核；静音立即停，停止不取消问题 | 两端设备录音/观察 |
| V7 | 重复上传/确认、轮询10次、ack失败重试 | 单条公开内容、单条邀请，已尝试内容不自动连续重播 | 自动测试+设备网络故障 |
| V8 | bob 查询 alice 私人草稿/任务；伪造作者或工具身份 | 401/403/404；无音频和私人配置泄漏 | API/MCP 自动测试 |
| V9 | 重启服务、重启客户端、断开 Linx/业务网络 | 内容与任务持久化；旧指令失效；不自动重播不确定内容；离线状态明确 | 部署及真实终端 |
| V10 | 转写迟到、空转写、录音配对不明、取消后确认回复 | 不发布错误内容，不把回复绑定到下一问题；保留草稿或明确失败 | 客户端/接口注入错误 |

三轮实时问答中每端均需有一次上行和一次下行原声验证。基本 A问B答已涵盖双方录音上传，但另测 A收邀请、B收回复，确认角色能力不是硬编码到单个账号。

每个角色在所属目录写 `HANDOFF.md`：实现任务ID、启动/构建命令、制品路径、实际环境、软件检查结果、平台检查结果、未完成项。真实部署地址可记录，凭证只记配置变量名。

验收分四层：代码与自动测试、单机部署、双端设备联调、静止环境用户体验。编译成功不能替代录放验收，原声业务成功也不能替代 Linx 与 MCP 成功；模拟输入始终标注。

## 4. 排期不足时

优先保留一个路口、真人问答、独立个人意愿、主动提示、任务状态与原声来源。先删同路/景区扩展、视觉细节和连续追问。固定提示和模拟位置属于既定范围。

真实 STT、MCP 或某端硬件未通时，只能降级为明确标注的部分原型，并报告缺口；不能称为完整双端验收。截止前保留最后可运行版本，修复有范围的阻断，不临时更换整套平台。
