# 2026-10-26｜公告恢复、信息当日有效与发布时间播报

生产 `20261026-day-validity-036`，保留032路线修复；Android **0.3.4/code15** 已覆盖安装 vivo V2405A。

## 原因与修复

生产三条模力社区公告仍为 published/until_withdrawn，未撤回、未替代，频道开启。公告因离开范围或位置采样失效而变成 `cancelled/OUTSIDE_SCOPE`；返回同次到访时仍按 visit_id 去重，即便本次只有 received、没有 played 也不恢复。

修复后，因 OUTSIDE_SCOPE 取消且本轮未播放的公告恢复待播并换新 request_id；旧回执保留。已播放、主动跳过及其他取消维持去重。位置、静音、频道及撤回检查保留。欢迎公告自动播，另两条身份相关短提示仍供主动查询。公告不建立真人回复上下文。

手机还存在跨到访过滤缺陷：旧 visit 的 attempted/deferred 被转成整个 delivery_id 排除，导致服务器新到访投递也不可见。现仅在本地按 visit key 过滤公告，旧到访不再提交为全局排除。另移除当日策略下自动候选的会话前30秒限制，覆盖当天仍有效的问题。

## 新规则

生产启用 `SONAR_INFORMATION_VALID_UNTIL_DAY_END=true`。问题、邀请、现场观察、普通有界公告和回答按 **Asia/Shanghai 发布当日24:00** 截止；线程回复还受原线程截止限制。取消、解决和撤回即时生效。有效期表示允许检索与收听的期限，不表示停车位等动态事实期间一直不变。

未配置开关的旧部署保留原TTL；新的 `.env.example` 显式启用当日策略。定位采样、会话、录音轮次、地图实时数据与私人助手临时结果的时效保持独立。此前用户指定长期有效的三条入园公告继续 until_withdrawn，不每天重发或改发布时间。

显式迁移当天动态信息，恢复每位作者最新、未回答且仅因时效过期的问题；不复活取消、已回答或被后续问题替代的任务。重复迁移补齐回退窗口内产生的短时邀请。不可变原消息、身份、profile、音频及回执保留。

原声 payload 保留 `published_at`，新增 `playback_intro`，例如“3分钟前发布。”或“2小时前发布。”；不到一分钟说“刚刚发布。”Android 自动收听、主动点听和语音选听均先用本机中文 TTS 播时间，再播放原始录音。提示后复核交付、request_id、revision、截止时间及本机静音/打断状态。私人人际实时聊天不加提示，未知发布时间不编造，原录音不改写。

ESP32 上行已适用服务端新时效；其播放端需固件读取 playback_intro 或用 server_time 与 published_at 计算相对时间后独立播提示。本次未改同事固件、未烧录，未宣称硬件播放验收。
