# 声呐 Android 界面约定

对象：途中提问者。单屏工作是录制问题、核对公开、等待现场回答并收听原声。

色彩：海蓝 #123E51（品牌与标题）、青色 #007F86（操作与有效状态）、浅灰蓝 #F0F5F5（底色）、墨色 #163440（正文）、淡蓝 #D8E8E9（边界）、琥珀 #966019（调试及未连接状态）。显示字使用系统 Serif 的 sonar，中文正文使用系统 Sans，倒计时和账号使用 Monospace。

布局：顶部身份与连接，录音卡，核对草稿，任务/回复卡，个人意愿与状态，明确标记的模拟位置。声呐同心圆仅围绕录音入口出现，体现接收声音；不以装饰动画暗示正在定位或真实后台监听。

模拟接口与手动转写标识始终可见。问题的“已回答”和音频的“已播放”分别展示。固定询问短提示来自macOS Tingting合成语音并加滴声，属于应用系统素材，不能冒充现场原声。

已在Android模拟器实际截图检查首页和回答状态；截图为运行制品，位于build/reports，不作为设计稿替代功能验收。
