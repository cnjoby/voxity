# 声呐 Android 界面约定

## 2026-10-24 车用免提约束更新

用户确认 App 与 ESP32 均用于车内，且各用自己的扬声器。[两端统一免提交互规范](../docs/design/ux-designs/ux-sonar-2026-10-24/EXPERIENCE.md)和[视觉状态约束](../docs/design/ux-designs/ux-sonar-2026-10-24/DESIGN.md)规定新的目标行为；尚未实现或实机验收，不覆盖本文记录的历史实现结果。

新默认是“会话授权的自然交流”：停车时一次开启本人现场语音自动分享和相关回复自动收听，明确范围；之后清楚现场发言可自动发布、相关原声在空隙自动播放，不逐条读回、问确认或等待播放口令。系统正常成功不播控制话术；用户开口和本地“停/安静”立即让路。审阅模式或关键歧义才使用自然澄清/确认。

新增可信授权、发言来源区分、语义动作和通用scene回复关系均待实现；现有assist/listen开关不能视为自动发布授权。安静暂停自动发布和普通播放；关麦结束会话。手机仍需实测熄屏麦克风、AEC、电话/音频焦点让路，旧Linx手动测试不替代。

配网、授权、隐私、编辑和复杂设置放在停车流程。屏幕仅镜像交流中、已分享、结果未知、回复播放中、安静等真实状态，不承担必需确认。下文描述旧停车调试路径，不再是默认车用流程。

## 既有界面与停车调试路径

首页服务途中提问者：说一句、确认发出、等回复、听原声。当前步骤占据主要卡片，录音、草稿与等待不会同时作为三个入口堆叠。回复后可再问一句。“安静一下 / 恢复收听”始终在首页可见，停止播放独立于结束提问。

海蓝 #123E51（标题）、青色 #007F86（主操作）、浅灰蓝 #F0F5F5（底色）、墨色 #163440（正文）、淡蓝 #D8E8E9（边界）、琥珀 #966019（提醒）。中文正文为系统 Sans；主页不展示用户ID和技术状态。声呐同心圆围绕可点按的录音入口，使用静态图形，不暗示后台监听。录音时按钮变化为停止标记，最多八秒。

“我的”是二级页面：互助意愿、个人关注、定位状态、连接状态；地址、凭证与 Linx 配置再进入“开发者连接”。退出二级页面保留录音草稿和等待任务。只在用户明确确认后公开录音，网络重试沿用原草稿与幂等ID。

模拟接口仍在首页明确标注。手动转写的限制在录音后的确认步骤和“我的”说明，不能暗示已经自动识别；文字补充不会冒充 STT。当前尚未接通正式语音识别，完整“一说就发”体验仍待 Linx 配置和实测。自动识别失败时保留私有草稿，允许重录并给出恢复路径。

正常模式使用前台原生定位和服务端 POI，首页显示询问目标与定位状态，点地点可换目标。旧模拟模式和模拟器位置明确标记。定位粗略时手选目标；定位过期不默认当作新问题的当前位置。收到邀请时优先显示回应卡，提示播完仍保留回应入口。首页不要求看地图或填坐标，见[定位接入](../docs/development/location.md)。

“已回答”和“原声已播放”分别展示。固定询问提示为合成系统素材，不能冒充现场真人声音。等待页说明保持应用打开，不能承诺尚未实现的后台通知。

验收：编译、JVM 回归、Android 模拟器 HTTP 闭环，以及首页、二级设置与回答状态的实际截图检查。模拟音频不代替真人语音识别和实体手机麦克风/扬声器验收。

个人关注为二级页面的一项自然语言设置。静音只修改收听状态，保留关注；模型、阈值与请求耗时不进入用户操作流程。Bamboo 筛选只影响主动邀请，不拦截本人已经期待的回答原声。

### 2026-10-24 三类声音

沿用首页白卡与海绿色，地点下方增加“听听这里的故事与公告”。在所选地点确认用途/公开范围后开始录音；发布前保留地点、用途、被回复原句/作者及必要有效期。运营告知显示授权主体、封闭演示标识、有效期和“POI 附近；未确认入口或楼层”；未知录制日期明确标记，不把收录时间当录制时间。上下文对话框与“我的”独立收听设置已在隔离模拟器检查实际渲染。
